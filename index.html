Оценка продуктивности

Оценка — ориентир, а не мера твоей ценности. Она складывается из выполнения задач (60%), привычек (25%) и использования запланированного времени (15%). Для корректной картины добавляй реалистичную длительность задач и временные блоки.

Синхронизация и резервная копия

Перенос данных между устройствами

В этой версии доступна полная выгрузка и восстановление данных через JSON. Автоматическая облачная синхронизация требует подключения к серверу и личного аккаунта — она не включается без твоих ключей доступа.

Аккаунт и облачная синхронизация

Один аккаунт для телефона и компьютера

Не подключено
Для включения облака нужен бесплатный проект Supabase. Создай проект, вставь URL и anon key, затем выполни SQL из файла SUPABASE_SETUP.sql, который будет в архиве. Ключ service_role сюда вставлять нельзя.

До подключения данные остаются только на этом устройстве.
