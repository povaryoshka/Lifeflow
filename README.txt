LIFEFLOW v3 — установка и запуск

ЧТО НОВОГО
- Календарь с месячным и недельным режимами; выбор даты открывает планировщик.
- Повторяющиеся задачи: каждый день, по будням, еженедельно или ежемесячно; можно задать дату окончания.
- Умные рекомендации на основе просроченных задач, процента выполнения за последние дни, привычек и распределения времени.
- Подготовлена облачная синхронизация и регистрация/вход через Supabase.
- Сохранены функции v2: цели, привычки, почасовой планировщик, статистика, дневник, уведомления, темы, JSON backup.

БЫСТРЫЙ ЗАПУСК
1. Распакуй архив.
2. Для теста открой index.html в браузере.
3. Для установки как PWA размести файлы на HTTPS-хостинге (например, GitHub Pages, Netlify или Cloudflare Pages) и открой сайт на телефоне.
4. В Android Chrome: меню браузера → «Установить приложение» / «Добавить на главный экран».

ВКЛЮЧЕНИЕ ОБЛАКА (НЕОБЯЗАТЕЛЬНО)
1. Создай проект на https://supabase.com/.
2. В панели проекта открой Project Settings → API (или API Keys) и скопируй Project URL и anon/public/publishable key.
   Никогда не используй service_role / secret key в браузере.
3. Открой SQL Editor в Supabase и выполни весь файл SUPABASE_SETUP.sql.
4. В LIFEFLOW открой «Данные и настройки» → «Аккаунт и облачная синхронизация».
5. Вставь Project URL и anon key, введи email и пароль, нажми «Создать аккаунт».
   Если включено подтверждение email, подтверди адрес, затем нажми «Войти».
6. После входа приложение загрузит данные из облака. Изменения на этом устройстве будут отправляться в облако автоматически; на втором устройстве войди в тот же аккаунт и выбери загрузку облачных данных.

ВАЖНО ПРО СИНХРОНИЗАЦИЮ
- Supabase-проект принадлежит тебе; архив не содержит и не может содержать твои ключи.
- При первом входе на другом устройстве приложение спросит, заменить ли локальные данные облачными. Выбирай внимательно.
- Синхронизация — снимок данных целиком (последняя запись перезаписывает предыдущую). Не редактируй одновременно один аккаунт на двух устройствах без ручной синхронизации: полноценного объединения конфликтующих изменений пока нет.
- Токен сессии хранится в localStorage этого браузера. Для публичных/чужих устройств не сохраняй вход.
- Если сессия истекла, войди снова.
- Экспорт JSON остаётся доступен как резервная копия.

ОГРАНИЧЕНИЯ
- Облачная синхронизация не заработает, пока не создан Supabase-проект, не выполнен SQL и не введены ключи.
- Уведомления о задачах проверяются, пока приложение открыто. Push-уведомления при закрытом приложении потребуют отдельного серверного push-сервиса.
- Данные без облачного подключения хранятся только в текущем браузере.
